# STAT107 Team 16 Final Project: Analysis of Election Candidate Data
Authors: Ananya Pandit(@ananyappandit), Melody Lu(@mlu097), Chiko Orji(@mrchiko31)

## Project Overview
This project analyzes two key aspects of American electoral politics:

1. Gender and Primary Success: How does candidate gender correlate with primary election success rates, and do these patterns differ by political party and office type?
2. Ideological Overlap Over Time: How does ideological overlap between Democrats and Republicans in Congress change over time?


### Data Sources
| Data Files | Description |
| --- | --- |
| `00_dem_candidates_2018.csv` | 2018 primary election democratic candidates data |
| `00_dem_candidates_2022.csv` | 2022 primary election democratic candidates data |
| `00_rep_candidates_2018.csv` | 2018 primary election republican candidates data |
| `00_rep_candidates_2022.csv` | 2022 primary election republican candidates data |
| `00_Political Polarization in US Congress (Assorted).csv` | Congress-level idealogy and polarization metric |
